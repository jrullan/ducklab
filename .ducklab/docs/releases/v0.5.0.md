# v0.5.0

# Release v0.5.0

- Generation loops are now detected and capped to prevent infinite repetition
- Project budget caps (max_tokens and named limits) are enforced on runs
- Chat wallclock budget is preserved when merging project settings
- Advisor can be configured with a custom seat and receives relevant project documents
- Advisor replies are validated against contracts, with failures and timeouts recorded
- Webhook notifications are sent for important run state changes
- Stage start and bug triage now support overrides for ducklings, mode, and agent_turns
- Fixed bugs and accepted tasks can now be reopened
- Bugs are only marked as fixed after a successful BUILD run
- Redo and relaunch operations require a note and are logged for audit
- Retired tests have a cleanup path, with a limit on redo commits per task
- Aborting a paused or failed build restores the working tree
- Retire-test errors now offer Clean or Commit recovery options
- Paused run cards display all available abort and reject actions
- Installed binaries include branch and commit provenance
- Accepted but unreleased work is now visible
